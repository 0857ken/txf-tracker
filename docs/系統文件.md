# TXF Tracker 系統文件（最新版）

台指期 + 股票 + 策略追蹤系統。純 serverless 架構，零伺服器、零成本。

## 一、整體架構

```
GitHub Pages (前端 · gh-pages 分支)
  index / stocks / assets / strategy .html
    │ 讀 JSON              │ 讀寫部位/資產
    ▼                      ▼
  data/*.json (repo內)    Firebase Firestore
    ▲ 定時寫入
GitHub Actions (排程 · main 分支觸發)
  ① market.yml    每30分   台指期報價+均線
  ② stocks.yml    盤中每時  股票現價
  ③ strategy.yml  每日14:00 0050 K線(策略用)
  ④ daily.yml     每天13:50 LINE 盤後總結+策略
```

核心原則：沒有常駐伺服器。運算在 GitHub Actions（定時）或瀏覽器（即時）完成。

## 二、四個頁面

| 頁面 | 用途 |
|---|---|
| index.html | 微台期主頁：報價、均線、部位、損益 |
| stocks.html | 資產總覽：台指期+股票+自訂資產 |
| assets.html | 200萬計畫：圓餅圖、現金水位、已實現損益 |
| strategy.html | 策略儀表板：三策略 tab + 走勢圖 |

## 三、資料儲存

### Firestore（使用者資料，跨裝置同步，匿名驗證）
users/me/ 下：
- positions/ — 台指期部位(date, type, lots, entry_price, note)
- stocks/ — 股票/基金(symbol, name, shares, cost_price, alert_high/low, is_fund, market, current_price)
- customAssets/ — 自訂資產(name, type, shares, cost, value, alert_high/low)
- realizedPnl/ — 已實現損益(date, lots, entry_price, exit_price, pnl_twd, note)

### JSON 檔（GitHub Actions 自動產生，放 repo/data）
- market_data.json — 台指期報價+均線(每30分)
- stock_prices.json — 股票現價(盤中每時)
- strategy_data.json — 0050 完整OHLCV(117天)+大盤序列(每日)

### localStorage（瀏覽器本機）
- profit_protect_pct — 獲利保護線百分比

## 六、排程（.github/workflows/，放 main 分支）

| 檔案 | 排程(台灣時間) | 用途 |
|---|---|---|
| market.yml | 每30分 | 台指期報價 |
| stocks.yml | 盤中每時(週一~五) | 股票現價 |
| strategy.yml | 每日14:00 | 0050 策略資料 |
| daily.yml | 每天13:50 | LINE 盤後總結 |

重要：workflow 放 main(排程只在預設分支生效)，但都 checkout gh-pages 執行、結果寫回 gh-pages。push 前用 git pull --rebase 避免併發衝突。

## 七、策略系統（strategy.html）

三個策略，頁內 tab 切換，各有結論橫幅+走勢圖+距離雷達+條件檢核+監視提醒。

### 策略一：耀的 RS 訊號
- Mansfield RS(50,5) + 神奇九轉 + 極端乖離軌道(23,60)
- 訊號：RS轉正+站季線+出量→買；RS轉負+破月線→賣；極端賣/FOMO→頂部過熱
- 圖：收盤+MA20+MA60+極端賣/買軌道+買賣訊號三角

### 策略二：橘太郎三條線
- 月線(20%)/季線(30%)/布林下軌(50%)分批進場，布林上軌出清，RSI≤20可加碼
- 圖：收盤+月線+季線+布林上下軌

### 策略三：月波動網格
- 基準 = 滾動20日最高(high.rolling(20).max())
- -3% 輕倉0.5碼 / -6% 重倉1.5~2碼 / -9% 戰備金全投入
- 停利：加碼單+5~8%出清 或 回MA20出清
- 圖：收盤+滾動20日高+三檔網格價水平線

### 跨頁 SOP
任一策略偵測到頂部過熱(極端賣/FOMO)時，其他策略的買進訊號會標警語「禁止追多」。

### 標的
策略訊號用 0050 現貨(0050.TW) 計算。指標全在前端(strategy-calc.js)或 Python(strategy_calc.py)自算。

## 九、日常維護

- 新增股票：在網頁新增，存 Firestore，下次 stocks.yml 自動抓價
- 手動觸發：GitHub → Actions → 選 workflow → Run workflow
- 改邏輯：改 scripts/*.py 或 *.js，push 到 gh-pages 即生效
- 前端顯示 undefined：module 載入時序，前端已用 waitInit 等待，重整即可
- 訊號跟 TradingView 對不起來：先查歷史序列天數、大盤日期對齊
