## 可獨立核算的數值

壓測測例是合成資料：指數20,000，TX 1口、MTX 2口、TMF 3口；期貨權益550,000、場外1,450,000，原始保證金100,000、維持75,000。

| 項目 | 預期 |
|---|---:|
| 每點持倉金額 | 330元 |
| 實際曝險 | 20,000×330÷2,000,000＝3.3x |
| 下跌10% | 18,000，跌2,000點 |
| TX / MTX / TMF損益 | −400,000 / −200,000 / −60,000 |
| 合計損益 | −660,000 |
| 壓力後期貨／總權益 | −110,000 / 1,340,000 |
| 回撤／風險指標 | 33% / −110% |
| 補回550%所需 | 550,000−(−110,000)＝660,000 |
| 補款後期貨／場外／總權益 | 550,000 / 790,000 / 1,340,000 |

另測490%風險：權益490,000、原始100,000，補回550%需要60,000；場外只有1,000時缺口59,000。恰好500%不觸發補款，月初整理則仍以550%為目標。

滑價測例：MTX跨月價差4口，arrival委買−20、委賣−18，中間價−19；成交1口−18、3口−17，均價−17.25。買價差arrival滑價＝1.75點，成本1.75×50×4＝350元。兩批等待3秒、7秒，加權等待6秒。價差名目金額−3,450另列，不當作滑價；費152、稅160時，換倉執行成本662元。

## 預覽與尚待驗收

`node scripts/defense-preview.cjs`產生`test-results/defense-preview.html`，內嵌公開行情與明確標示的示範帳戶，禁止連線雲端；可以核對公式和表單。預覽紀錄只留在開啟檔案的瀏覽器，不能當成每日自動儲存或真實Forward實績。

現有Netlify整合發布的是舊frontend資料夾，其PR預覽不含本頁。請使用這次交付的HTML檔或上方GitHub工作下載的artifact，不要把舊Netlify畫面當成第4策略預覽。

- **手機實際畫面未驗證**：control-browser安全政策拒絕本機預覽URL。沒有繞過政策；JSDOM不執行CSS排版，不能代替iPhone Safari驗收。尚無已驗證的畫面截圖。
- **正式Firestore、券商帳務、每日排程未實測／未啟動**：沒有讀取Secret、修改安全規則或寫入正式帳戶。資料交易以模擬Firestore驗證，不能據此宣稱正式權限已通過。
- **固定規則缺兩個判定**：MA20相等（且非<=MA10）與MA線交錯重疊時顯示待確認；換倉日期由帳戶明確填入，不擅自把結算日指定為換倉日。
- **理論績效範圍**：目前是有清楚標示的加權指數理想參考，尚非可成交期貨理論帳本；歷史研究沒有匯入，未混入Forward。沒有券商資料的日期只做估值，不假裝真實每日實績。
