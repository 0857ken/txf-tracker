🎯 進場原則
• 多頭排列（5日>20日>60日）→ 收割模式，建倉
• 5日穿越月線 → 進攻模式，加碼
• 均線走平 → 觀察模式，減碼
• 空頭排列 → 防禦模式，空手或反手
💰 加碼規則
• 收紅K → 留倉
• 收黑K → 當日加碼單出清
• 突破前高 → 順勢加碼1口
🚨 停損規則
• 動態最後防線 = 平均成本 - 100點
• 跌破最後防線 → 全數清倉，不留情
• 距最後防線 ≤ 300點 → 警戒，準備出場
⚠️ 風控原則
• 單筆最大虧損不超過總資金 5%
• 連續虧損3次 → 強制休息1週
• 盤中情緒不穩 → 立即停手
📝 心法提醒
• 順勢交易，不逆勢
• 賺錢讓他飛，賠錢趕緊跑
• 計劃你的交易，交易你的計劃
